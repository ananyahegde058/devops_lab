02 — Research

Publication

Scientific Reports · Nature · 2026 DOI: 10.1038/s41598-026-61100-w ↗

TCP Congestion Control Performance Evaluation in Cloud-Based Networks

An independently designed and implemented experimental system comparing TCP Cubic, Reno, and BBR across four distinct workload types, run on a 4-node dumbbell topology built on AWS EC2 (m7i-flex.large) with a dedicated forwarding node and static routing forcing all traffic through a single contention point.

Automated workload generation across iperf3, Kafka & Flink, and Hadoop TeraSort measured throughput, latency, retransmissions, and job completion time — producing workload-specific congestion-control guidance for multi-tenant cloud deployments.
